# AI Image Generator Chatbot

A modern Flutter-based AI chatbot application that can generate images from text prompts and provide conversational AI responses in a clean and interactive chat interface.

---

## 📱 Features

- 🤖 AI Chatbot conversation system
- 🎨 AI Image Generation from text prompts
- 💬 Real-time chat interface
- 🖼️ Display generated images inside chat
- ⏳ Typing/loading animation
- 📱 Responsive Flutter UI
- 🌙 Clean and minimal design
- 🔗 API integration for AI responses and image generation

---

## 🛠️ Built With

- Flutter
- Dart
- REST API
- HTTP Package
- Material 3

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ai_image_generator_chatbot.git
```

### 2. Go to the project folder

```bash
cd ai_image_generator_chatbot
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```

---

## 🔑 API Setup

Add your API key inside your service file.

```dart
const String apiKey = "YOUR_API_KEY";
```

---

## ✨ App Workflow

1. User enters a text prompt
2. App sends request to AI API
3. AI generates:
   - Chat response
   - AI generated image
4. Results are displayed in the chat UI
